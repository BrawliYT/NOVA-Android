# NOVA Android 0.3.2 notes

- Version name 0.3.2 / version code 4.
- NOVA icon resources and app-bar mark.
- Theme accent customization.
- Chat search/rename/delete and local persistence.
- Speech-to-text and Android TextToSpeech read-aloud.
- Model/provider selector for Gemini, OpenAI, Claude and DeepSeek with editable model IDs.
- API keys encrypted locally with Android Keystore.
- Local LiteRT-LM model import remains separate from provider API modes.

Cross-device Google sign-in/chat synchronization is not wired yet; it needs app-specific Firebase/OAuth setup and security rules. This release does not claim cloud sync is functional.
